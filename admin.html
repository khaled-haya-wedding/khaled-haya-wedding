إنشاء روابط مفتوحة

Links that aren't tied to a name. Send one link to each person: they type their name, and after they register the link locks to them and they get their entry ticket. An Excel file with the new links downloads, and the links appear in the "الروابط المفتوحة" tab so you can see who used each one.
